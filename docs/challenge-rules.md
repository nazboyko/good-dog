# Challenge rules and judging

DEV Weekend Challenge: Dog Days Edition. Prompt: build something for, about, or inspired by dogs.

## Timing, official clock is the sponsor's servers
- Start: August 14, 2026 at 02:00 UTC
- Deadline: August 17, 2026 at 06:59 UTC, that is Sunday 23:59 PDT, about Monday 01:59 CDT
- Publish the submission by Sunday 20:00 CDT at the latest, do not gamble on the last hour
- Winners announced September 10, 2026

## Submission
- One post on dev.to using the official template, required tag #weekendchallenge
- Sections: What I Built, Demo, Code, How I Built It, Prize Categories
- One submission per person, one win per person per challenge
- Multiple prize technologies in one submission qualify for multiple categories at once

## Project rules
- New projects only, repository created and work started inside the window
- Judges review commit history as part of judging
- Commits after the deadline are allowed but must be noted in the readme, otherwise disqualification
- Open source reuse is fine if changes are significant, credit every non trivial dependency in the submission
- AI tools fully allowed
- English required for prize eligibility, language mastery is not judged

## Judging criteria, equally weighted
1. Relevance to theme
2. Creativity
3. Technical execution, this includes the commit history
4. Writing quality, the article is half the submission
5. Use of prize category technology, optional: Snowflake, Solana, ElevenLabs, Google AI

Tie break between judges goes to the post with more positive reactions. Publish early, answer every comment, share on LinkedIn right away.

## Our category strategy
- Google AI: two step grounding, structured outputs, later audio understanding for real bark mode
- ElevenLabs: distinct voice per dog via library voices plus settings, sound effects API for the shelter soundscape
- Both are depth of platform features, not hello world calls. Highlight both in How I Built It
