## Day 1
- The reveal landed on the first playtest until the photo, then a listing block turned the moment into a product card. Three passes fixed it: one line at a time after the photo in the opening rhythm, reserved space plus fade so nothing jumps by a pixel, and a button pair with the one loud thing on the screen. Every fix was measured, not eyeballed: the browser's own layout shift observer read zero across the whole reveal.
- The session state machine landed as a pure function over a day table: Step(rails, state, input). The prototype's flat rails became the short run, the three day full run sits beside it, and a breadth first search over both proves every state reaches an ending. Persisted state refuses a version, beat or day this build does not know, so a resume can never guess.
- Visitors arrived with a pure comfort function: the signal times hidden preferences, graded into five bands, and the only readout is a body. Phone, next kennel, watching, a crouch, a hand flat on the gate. No number ever reaches the player and the mismatch narrator stays the only place intent and perception are named.
- Two guardian passes caught what the tests could not. The narrator said the bark was heard as too loud while the visitor's body crouched down in the same fade, which teaches a player the narrator lies. A mechanical guard now pairs every heard line against every archetype's warmth, so a future archetype cannot reopen it. The second pass caught the other half: half of all first plays end with nobody, and that path ended on four lines of rejection with nothing landing the beat.
- The visitor who came for another dog is the whole point. He can never take you home, playing well means he is late for the dog he came for, and the parting says so in his own words. Nothing in it reads as the player having done badly, which is the rule the copy tests now enforce with a blame word list.
- An invisible layer still caught clicks: the faded out vocalization panel sat under the narrator text, so pressing where a button used to be fired a phantom signal and surfaced a server error. Reserved space plus fade now also means pointer events none while hidden.
- Two traps for the article: overflow-x hidden on a flex shell forces overflow-y auto and paints a scrollable view black past the fold, and editing a shared engine module mid session left a Vite HMR graph with a stale import that only a dev server restart cleared. Both cost real time and neither was the code.
- A visit is four answers now, not one, and that is what finally gave the man who came for another dog his whole range. One signal could never move him past watching, four can. When the scene closes, one line names the shape of what happened: closer than when she stopped, further off, no closer and no further, or moved once in the middle and ended where she started. It is a shape, never a score, and the tests reject any word in it that reads as a verdict on the player.
- Adding the fourth exchange broke the proof that every state reaches an ending, and the proof stayed green. The reachability key had no field for how many answers the scene was holding, so two different states looked identical to the search and it pruned the only path to the end. A search that prunes real paths is worse than no search, because it reports success.
- Measuring the reserved slot taught the difference between the worst case you can write and the worst case a player can reach. Pasting the longest line of each kind together gave 422px at 320 wide. But meant and heard always come from the same signal, and the body and the parting both come from the same band, so the tallest close anyone can actually see is 369. Enumerating every reachable combination is the only honest floor, and the acceptance test is not the number, it is that the lines above the slot never move.
- A test disarmed itself and stayed green, and it took two reviewers coming at it from opposite ends to see it. The rule was that a signal the visitor heard badly can never leave them at their warmest, and there was a test named after it. Going from one exchange to four made the band cumulative while the mismatch narrator stayed per signal, so answering silence, silence, silence, growl put "she heard: maybe not this one" directly above "She puts a hand flat against the gate." The test did not fail, because updating it for four exchanges meant building a scene of four identical answers, and a uniform scene is the one family where the two lines can never disagree. The test still named the rule in its comment and no longer checked any part of it. The guardian read the screen and called it a contradiction in the copy. The clean context reviewer read the diff and called it a rule the test had stopped enforcing. Neither would have been enough alone: the guardian could not see that the guard was gone, and the reviewer could not have known which of the two lines should give way. The body from the second answer on now says where the visit stands rather than what the last answer did, and the test walks all 1296 mixed scenes instead of the 6 uniform ones. Lesson for the article: when a test is updated to match a changed shape, check that it can still fail. A test rewritten alongside the code it guards is the easiest thing in a codebase to quietly turn off.
- The guardian also caught the thing the whole archetype exists for. The man who came for another dog explains himself when the visit goes well and says nothing when it goes badly, because the reason lived in one branch of the parting. Four low growls gave five lines of rejection with the player as the only visible cause. The reason is one sentence on the archetype now and every outcome opens with it. The test that was supposed to guard this passed an outcome and a band that the game cannot actually produce together, so it proved nothing about the two bands where the reason was missing.
- The arc line lied about where the visit started. It compared the end against the band after the first answer, not against where the visitor stood before the dog made a sound, so a dog could spend the whole visit one rung down and still be told the visitor is closer now. Seeding from the gate fixed the line and deleted the sentinel in the loop.
- Mutation testing earned its keep and then cost an hour. Every new guard was checked by putting its bug back, and all five failed the intended test, including one the reviewer had predicted the old marshal comparison could not see. Then the tidy up line in the check script, git checkout on the internal directory, threw away every uncommitted Go file in the unit. Not the mutation, the whole unit. It only existed in the working tree, and checkout does not know the difference between the change you just made and the day of work under it. The diff came back out of the gate 1 subagent transcript, which had run git diff on the same tree twenty minutes earlier, so the recovery was a patch file assembled out of a review log. Three things worth keeping: mutate against a file copy and restore from the copy, never reach for git to undo something git was never told about, and a subagent that reads your diff is holding a backup nobody planned. CLAUDE.md now says so under gate 2.
- Do not trust a browser pane that is not fronted. With document.hidden true the transitions stop ticking and timers throttle to about a second, so a layer mid fade reads opacity 0 and a click looks like it did nothing while its request is still in flight. Chased a phantom stale UI bug on exactly that before thinking to check document.hidden. Layout stays correct, so measure geometry and assert the class the client applied, never the opacity.
