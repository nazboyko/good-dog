# Devlog

Three to five lines after every major block: what was decided, what was cut, what surprised. The article gets assembled from this file.

## Day 0
- Steel thread spike ran first, five checks before real work. SSE through the Vite proxy, click gated audio with range support, and the dog vision color matrix shader all went green in the browser on the first real try.
- ElevenLabs went green too: key valid, George voice picked for the radio, one probe call landed a real mp3. Budget guard and disk cache written with tests before the first paid call.
- Gemini code is done and unit tested, but the live call is blocked: the key's Google project has quota_limit_value 0 for the API, every model returns 429. Needs billing enabled or a fresh AI Studio key.
- Surprise of the day: the shader screenshot looked right but the color matrix was applied transposed, uniformMatrix3fv reads column major. A clean context reviewer caught what the eyeball test missed. The guardian also caught the extraction schema forcing invented moods on sparse notes, both fixed before commit.
- Linear space gotcha: the Vienot matrix is defined for linear rgb, applied to srgb encoded pixels it drifts green. Linearize, multiply, desaturate 15 percent in linear, then encode back. readPixels swatches assert red goes muddy yellow, green goes pale yellow, blue stays blue. The corner strip is spike page only, the real game view draws verification offscreen.
- Model retirement gotcha: the 2.5 flash line still shows in ListModels but carries zero quota for new projects, which reads exactly like a dead key. gemini-3.6-flash works on the same key. The server now preflights ListModels at startup and warns when the pin is missing, detect only, never auto switch. The retirement also renamed the thinking control, thinkingBudget 0 became thinkingLevel minimal, a 400 told us.
- Animal provider layer landed: one sanitize pipeline where block tags become sentence breaks so extracted facts keep their edges, pool filter counts runes, and the two synthetic shape examples carry a flag Search refuses. The guardian pushed the flag idea: a fake dog reaching a player would break layer one, so the gate is mechanical, not a comment.
- Dog sheet compiler landed: structured fields become facts without the model, description facts must be verbatim quotes or they are dropped, every inference cites fact ids, fears carry the supporting quote, and a mechanical verifier rejects what it cannot trace. The guardian then found two holes the tests missed: no shelter facts class, and adopt language sneaking through when a listing mentions adoption. Both are now forbidden unconditionally in generated text.
- Free tier reality check: gemini gives 20 generate requests per day per model. The eval run passed 4 profiles, both injection ones included, then starved. The runner now tells quota starvation apart from grounding failure and aborts instead of burning retries for 25 minutes. Weekend content generation needs paid tier or it does not happen.
- Bella is real: first curated dog in the fixtures, verbatim listing, her own eval profile guarding against senior stereotypes. Her sheet compiles the moment quota exists.
- Twelve real dogs curated by hand, 6 lbs to 78 lbs, ten weeks to eleven years. Thirteen were collected and Smudge was cut: every sentence on his page also appears on another dog's page, his opening line word for word Preston's, so a player could not have told you afterward who he was. Source style predicted texture exactly, all five thin dogs came from the templated shelter, all seven rich ones include every foster written listing. Three of the twelve are named Bella, which is real and looks like a bug.
- We almost poisoned our own well with a paragraph about oil changes. A senior dog's listing ended with the rescue's stock blurb comparing old dogs to vintage cars, tune ups at the vet, oil changes meaning meds, normal lumps and bumps. His own listing says nothing about his health. Left in the description it would have handed the extractor a medical claim that passes the quote check, because the words really are on his page. Category boilerplate is now stripped at curation, and the test is whether the paragraph could move to another dog's page unchanged.
- The human picked the prettier link, the review picked the true one. A rescue's own adoptable animals page looked better than a bare Shelterluv embed url, but the page renders its list client side and has no per dog link, so the reveal would have dropped the player into a grid of other dogs. The embed resolves to her record by name. Rule now lives in the animal-provider skill: the reveal link must resolve to this specific dog, the shelter page belongs on the organization.
- A crossed photo passed every existing check: real url, right domain, 200, correct dimensions, and the pool filter only asks whether a photo url is present. Two dogs would have shared one face through the reveal. Only a content hash caught it, so fetch-photos now records sha256 per photo in a cache manifest, names both dog ids when two hashes match, and reports a cached file that changed underneath us.
