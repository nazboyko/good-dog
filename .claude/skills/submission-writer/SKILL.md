# Submission writer

## Structure
Follow docs/article-draft.md: What I Built, Demo, Code, How I Built It, Prize Categories, The Bell, Every dog in this post is real.

## Style
Natural conversational english. Short sentences, no filler, no buzzwords, no em dashes, no emoji. Never delve, leverage, seamless, robust, game changer. One strong paragraph beats three average ones. Concrete numbers over adjectives: name the count of real dogs, the eval dataset size, the exact trade offs.

## Musts
- Each How I Built It part carries one number or one decision with a trade off
- A what I cut and why section, judges read it as engineering maturity
- Credit every non trivial dependency, keep the running list from the readme
- First image is the epilogue screen, the video ends on the reveal
- Pull real quotes from docs/devlog.md, do not invent hindsight
- Note the v0.1.0-challenge tag and the post deadline commits line
